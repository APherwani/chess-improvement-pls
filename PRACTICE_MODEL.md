# PRACTICE_MODEL.md

## Topic

Chess rapid improvement.

## Current Level

1710 chess.com rapid.

## First Goal

1850 chess.com rapid.

## Later Stretch Goal

2000 chess.com rapid if progress and enjoyment remain strong.

## Core Attempt Unit

One serious rapid game per day, followed by structured review.

## Main Improvement Mechanism

Extract recurring decision errors from your own games and repair them with targeted review or drills.

## Daily Game Rule

- Play one serious rated rapid game.
- If the opponent blunders massively and the game ends in under 5 minutes, a second rated game is allowed.
- If you blunder massively, continue the game and review it.
- Maximum two rated games per day.

## Review Phases

### Phase 1: Memory Dump

Before engine analysis, capture what you actually believed during the game.

Use [templates/game-review-template.md](/Users/arjun/dev/chess-improvement-pls/templates/game-review-template.md).

### Phase 2: Human Analysis

Still before engine, identify 3 to 5 critical moments and write:

- candidate moves considered
- move you would choose now without engine
- evaluation guess
- line calculated
- what felt unclear

### Phase 3: Engine Comparison

Use the engine only after the human pass. Translate engine moves into chess ideas:

- tactical resource
- defensive resource
- piece improvement
- king safety
- pawn structure
- square control
- initiative
- endgame conversion
- exchange evaluation
- move-order issue
- prophylaxis

## Review Output Limit

For one game, log at most:

- 1 biggest tactical miss
- 1 biggest strategic or positional miss
- 1 biggest time-usage or decision-process miss
- 1 next-game focus

## Repair Rule

Repairs must come from:

- your own game positions
- directly similar positions
- a promoted gap supported by repeated evidence

Do not create broad drills detached from actual misses.
